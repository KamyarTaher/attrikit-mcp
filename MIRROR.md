# Read-only source mirror

This repository mirrors `packages/mcp` of the AttriKit monorepo. Releases ship from npm as
[`@attrkit/mcp`](https://www.npmjs.com/package/@attrkit/mcp); install it with `npx -y @attrkit/mcp`.

The source imports a workspace-only package (`@attrkit/shared`), so it does not build on its own
outside the monorepo. Issues and questions are welcome here or at contact@clashware.com.

Docs: https://attrikit.io/en/docs/mcp
